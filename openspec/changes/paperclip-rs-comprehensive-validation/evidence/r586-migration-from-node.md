## 4. 关键决策

### 4.1 协议层 100% 兼容

明确声明兼容层（HTTP API / WS / OpenAPI / DB / 插件 manifest / CLI），让用户对迁移有信心。

### 4.2 三种迁移模式

- **蓝绿**：零停机，但需要临时双倍资源
- **灰度**：按 cookie / header 分流，验证友好
- **全量**：直接切换，最简单但有短暂中断

### 4.3 验证脚本一键化

提供 `verify-migration.sh` 自动跑：DB 表数 + /health + OpenAPI 路径数 + V11 60 clients。任意失败 exit 1。
